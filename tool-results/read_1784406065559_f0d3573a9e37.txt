    91→## Task 6+10: Authentication & API Routes
    92→- **Agent**: Auth & API Agent
    93→- **Date**: 2024-01-01
    94→- **Status**: Completed
    95→
    96→### API Routes Created (15 endpoints):
    97→
    98→1. **`/api/auth/register`** - POST: User registration with validation, auto-creates wallet + welcome notification
    99→2. **`/api/auth/login`** - POST: Login with email/password, updates lastLogin, creates login notification
   100→3. **`/api/auth/me`** - GET: Current user profile with wallet and KYC data (Bearer token auth)
   101→4. **`/api/tickets`** - GET: List tickets with filtering, search, sorting, pagination; POST: Create ticket with auto-generated ticketId, platform fee calculation
   102→5. **`/api/tickets/[id]`** - GET: Ticket details with view count; PUT: Update ticket (seller/admin); DELETE: Soft delete
   103→6. **`/api/orders`** - GET: List orders by role; POST: Create order with escrow hold, transaction safety
   104→7. **`/api/orders/[id]`** - GET: Order details with chat, reviews (buyer/seller/admin)
   105→8. **`/api/wallet`** - GET: Wallet with transactions; POST: Withdrawal request with balance validation
   106→9. **`/api/kyc`** - GET: KYC status; POST: Submit/resubmit KYC documents
   107→10. **`/api/admin/stats`** - GET: Dashboard stats, charts data, recent activity (admin only)
   108→11. **`/api/admin/users`** - GET: List users with search/filter (admin only)
   109→12. **`/api/admin/kyc`** - GET: List KYC applications; PUT: Approve/reject with auto role upgrade (admin only)
   110→13. **`/api/notifications`** - GET: User notifications with unread count
   111→14. **`/api/settings`** - GET: Public settings and transport companies
   112→15. **`/api/seed`** - POST: Seeds DB with 1 admin, 5 users, 3 sellers, 12 tickets, 12 companies, settings
   113→

   115→
   116→1. **`/components/pages/LoginPage.tsx`** - Emerald-themed login with email/password, show/hide toggle, remember me, forgot password link, Google placeholder, animated transport icons, gradient background
   117→2. **`/components/pages/RegisterPage.tsx`** - Registration with name/email/phone/password/confirm, password strength indicator, requirements checklist, terms checkbox, auto-login on success, same emerald design
   118→
   119→### Key Technical Decisions:
   120→- All auth uses Bearer token from Authorization header with custom JWT verification
   121→- Counter model for sequential ticket/order IDs (ETR-00000001, ORD-00000001)
   122→- Platform fee: max(20 BDT, 2% of price)
   123→- Escrow system: order creation marks ticket sold, increments seller's wallet escrow
   124→- Soft delete pattern for tickets (status → cancelled)
   125→- KYC approval auto-upgrades user role to verified_seller
   126→- All routes include comprehensive error handling and input validation
